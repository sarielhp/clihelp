# mail\_cli filter

Manage remote filters on Gmail.

## Usage

```
mail_cli filter <subcommand> [args...]
```

## Subcommands

| Command | Description |
|---------|-------------|
| list | List all remote filters on Gmail with detailed action descriptions. |

## Examples

- `mail_cli filter list`
