# mail\_cli labels del

Delete an existing label by its name.

## Usage

```
mail_cli labels del <lbl_name>
```

## Parameters

| Parameter | Description |
|-----------|-------------|
| `<lbl_name>` | The name of the label to delete (e.g. "temp-label"). |

## Examples

- `mail_cli labels del "temp-label"`
