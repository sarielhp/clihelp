# mail\_cli labels cache

Manage the labels cache used by the search subcommand.

## Usage

```
mail_cli labels cache <subcommand>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [update](labels-cache-update.md) | Update the labels cache from the server. |
