# podctl status

Check RSS feed health, CDN metrics, and download stats

## Usage

```
podctl status [options]
```

## Flags

| Flag | Description |
|------|-------------|
| `-s, --stage STAGE` | Environment to inspect |
| `--json` | Output metrics and status in JSON format |
