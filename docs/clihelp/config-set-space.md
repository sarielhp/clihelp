# podctl config set space

Set maximum disk space allocation in MB

## Usage

```
podctl config set space <megabytes> [options]
```

## Flags

| Flag | Description |
|------|-------------|
| `--unit SIZE` | Space allocation unit |
| `--auto-cleanup` | Purge oldest temporary cache files |
